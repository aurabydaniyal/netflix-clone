> A fully responsive Netflix clone built with React.js and Tailwind CSS, featuring real movie data from TMDB API, video trailers, search functionality, and smooth animations.

## ✨ **Features**

### 🎯 **Core Features**
- ✅ **Dynamic Movie Rows** - Horizontal scrolling sections with Netflix-style hover effects
- ✅ **Hero Banner** - Featured movie with auto-playing background and gradient overlay
- ✅ **Movie Modal** - Click any movie to view details and watch YouTube trailer
- ✅ **Real-time Search** - Search thousands of movies and TV shows
- ✅ **Responsive Design** - Perfectly works on mobile, tablet, and desktop
- ✅ **Loading Skeletons** - Professional loading states for better UX

### 🎨 **UI/UX Features**
- ✅ **Sticky Navbar** - Changes background on scroll (transparent → black)
- ✅ **Hover Animations** - Movie cards scale up with overlay effects
- ✅ **Smooth Scroll** - Programmatic scrolling with chevron buttons
- ✅ **Backdrop Blur** - Modern glass-morphism effects
- ✅ **Custom Scrollbars** - Hidden scrollbars for clean design

### 🚀 **Advanced Features**
- ✅ **Custom Hooks** - Reusable `useFetch` hook for API calls
- ✅ **Error Handling** - Graceful fallbacks for failed API requests
- ✅ **Environment Variables** - Secure API key management
- ✅ **Optimized Images** - Lazy loading and fallback images

## 🛠️ **Tech Stack**

### **Frontend**
| Technology | Purpose | Why Chosen |
|------------|---------|-------------|
| **React 18** | UI Framework | Component-based architecture, hooks, ecosystem |
| **Tailwind CSS** | Styling | Utility-first, rapid development, responsive |
| **Axios** | API Calls | Promise-based, easy interceptors |
| **React Player** | Video Player | YouTube/Vimeo support, customizable |
| **React Icons** | Icons | Netflix-style icons, massive library |

### **API & Data**
| Service | Purpose |
|---------|---------|
| **TMDB API** | Movie database (posters, descriptions, trailers) |
| **YouTube API** | Trailer video embedding |
